# Dados

Coloque aqui somente `KDDTrain+.txt` para executar a primeira entrega. O arquivo tem 43 colunas, sem cabeçalho: 41 atributos, rótulo de ataque e nível de dificuldade.

O conjunto `KDDTest+.txt` deve permanecer fora da análise e dos experimentos até a avaliação final. Os arquivos de dados são ignorados pelo Git; cada integrante deve obter sua própria cópia da [NSL-KDD](https://www.unb.ca/cic/datasets/nsl.html) ou do [espelho indicado no enunciado](https://www.kaggle.com/datasets/hassan06/nslkdd).

Registre no README principal a origem e o hash SHA-256 do arquivo efetivamente usado antes da entrega.
